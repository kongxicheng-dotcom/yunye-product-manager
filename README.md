# 云野家具 · 产品管理 V1.2

## 新增：产品参数文字 + 白底图联合导入
1. 在「图文联合导入」里粘贴带字段标签的规格文字。
2. 在同一位置选择白底图，也可以将复制的图片粘贴到文字框。
3. 点击「识别参数」，查看字段归类预览。
4. 点击「将识别结果填入表单」，检查并补齐产品名称、分类等。
5. 点击「保存产品」。

**限制：** 图片作为产品主图保存，不会自动分析图片得出材质、颜色、尺寸等内容。文字使用免费离线规则识别，格式不规范可能漏识或误识；必须人工核对。支持明确的 cm/mm 和 kg/g 换算。

沿用本地存储键 `yunye_products_v1`，升级前先导出 JSON 备份。更换设备不自动同步。
