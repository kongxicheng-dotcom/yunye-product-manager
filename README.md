# 云野产品管理系统 V1.6 — 白底主图与六视图归档

## 新功能
- 每个产品型号对应 1 张白底主图及 6 张视角照片（正、后、左、右、俯、仰），可分别上传、替换、删除、下载压缩预览图。
- 选择型号和图片类型后快速上传，也支持点击粘贴区域按 Ctrl+V 粘贴图片。
- 显示浏览器本地存储使用量估算；保留尺寸照片标注 PNG 功能。
- 不调用付费 AI。请在 ChatGPT 单独生成白底图并下载，再上传本系统。

## 升级和备份
1. 在旧版本中，导出 **产品备份 JSON** 和 **图像工作台备份 JSON**，另存高清图片原件。
2. 在 GitHub 仓库将根目录 `index.html` 全文替换为此文件并 Commit。
3. 更新后刷新页面（Ctrl+F5），确认显示 V1.6，检查已有产品和图像。
4. 旧版继续使用 `yunye_products_v1` 与 `yunye_views_v13` 的 localStorage 键；若网站域名、浏览器和数据格式未改变，原数据应继续可见。旧版的原始实拍 photo 分类保留在备份中，但 V1.6 页面不显示。
5. 若要迁移设备，先恢复产品 JSON，再恢复图像 JSON；两者均为覆盖式导入，操作前先备份。

## 重要限制
- 本地浏览器空间有限，上传的图片压缩到最长边 900px 并以 JPEG 0.72 质量保存，仅供资料管理；并非白底高清原件。高清原图必须另存电脑。
- 无账号登录、云端同步、AI 自动出图或自动测量。正式尺寸须人工校验。
- 如果之前浏览器中存在很多图片，可能会达到 localStorage 配额限制。
